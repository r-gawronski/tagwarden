# Security Policy

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it privately through GitHub: open the repository's **Security** tab and click **Report a vulnerability**. Include the affected version, a description, and steps to reproduce if you have them.

## Supported versions

Tagwarden is pre-1.0. Only the latest minor release receives security fixes.

| Version | Supported |
|---------|-----------|
| Latest minor (0.x) | Yes |
| Older releases | No |

## Response targets

- Acknowledge the report within 3 business days.
- Triage and give an initial assessment within 10 business days.

## Disclosure

We follow coordinated disclosure. We agree a fix and a disclosure date with the reporter. When the fix ships, we publish a GitHub Security Advisory and request a CVE through GitHub. Reporters are credited unless they ask not to be.
